# Mental Data Explorer
Mental Data Explorer is a software for exploring mental health data and understanding the importance of mental health.
___
## About me
I am a Computer Science student. Over time, I noticed that I was only programming with AI and had forgotten how to build software projects on my own. So it was important to me to create a project that I can keep expanding to improve my skills in bad data and data engeneering. I use AI only for research and write all the code myself.
Mental health is a topic that I feel still gets too little attention in our society, which is why it form the foundation of this project.
